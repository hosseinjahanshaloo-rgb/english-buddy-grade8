# English Buddy (Prospect 2 – پایه هشتم)

ساخت APK بدون اندروید استودیو:
1. در GitHub یک repository جدید بسازید و همهٔ این فایل‌ها را آپلود کنید.
2. به تب **Actions** بروید؛ بعد از چند دقیقه ساخت تمام می‌شود.
3. روی آخرین اجرا کلیک کنید و از پایین صفحه، **EnglishBuddy-APK** را دانلود کنید (zip است؛ داخلش app-debug.apk).
4. APK را روی گوشی نصب کنید (نصب از منبع ناشناس را اجازه دهید).
